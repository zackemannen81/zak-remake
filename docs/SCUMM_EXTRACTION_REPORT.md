## Background exporter — proven path

The A008 workflow ported the SCUMM v2 EGA background decoder to Python 3 instead of requiring Python 2, and used the machine's existing Pillow installation. It reads `ROv2/HDv2` for dimensions and `ROv2/IMv2` for image data, then writes index-color PNGs. A008 first tested a single room (320×128, 16-color), then batch-tested all 58 and verified generated outputs. Existing files should be treated as verified reference outputs, **not regenerated by default**.

## Object export — findings and failed assumptions

1. Raw object pixels reside in `OIv2`; related object code/metadata is present in `OCv2`. ScummVM's v2 code indicates the object's size and resource associations must be resolved from original room structures.
2. A suffix-equivalent `OIv2_####` / `OCv2_####` pairing exists at raw-file level, **but it did not reliably yield valid image dimensions or decodable streams**. Matching suffixes are therefore not an accepted mapping algorithm.
3. A008 noted positive height from the tested `OCv2` fields for only 193 of 578 suffix-paired candidates. This is a diagnostic observation, **not** evidence of 193 correct object mappings or successful sprites.
4. A008 inferred that the actual room object lookup involves offset tables in complete LFL/room resources. The `scummrp` split dump omitted the intact enclosing room table, and a trial `scummrp -t RO` did not recover it as a standalone room record.
5. Several trial decodes failed under candidate widths/heights. The cause may involve incorrect metadata association, offsets, object frame structure, decoding assumptions, or combinations of these. Do not declare the decoder correct or generate guessed object PNGs.
6. The bundled `SCUMMXP.exe` was launched but did not produce a usable visible GUI in the inspected Windows session. Its manual describes image export, but working batch export was **not demonstrated**.
7. A standalone open-source SCUMM image tool was reviewed and found useful for **backgrounds only**; it does not establish object export support.
